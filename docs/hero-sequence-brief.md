# ARQIA — Hero Scroll Sequence Brief (Chair A)

## Goal
Create an Apple-level, photoreal, scroll-driven "moment of creation" that lasts **briefly** (fast handoff to Collections). The sequence will be rendered as frames and scrubbed by scroll on the homepage.

## Visual Reference
Chair style: **A — X-frame walnut + white upholstered cushions** (sculptural wood arms, minimal silhouette, quiet luxury).

## Concept (3 short beats)
Total scroll duration target: **~1.4–1.8 viewport heights**.

1) **Material (0–40%)**
   - Wood blanks + fabric panels + a few tools appear (subtle float-in; not chaotic).
   - Warm studio light. Clean background.

2) **Craft (40–75%)**
   - Parts align and assemble into the chair.
   - Motion should feel precise, calm, and deliberate.

3) **Reveal (75–100%)**
   - Finished chair settles into a hero angle.
   - Optional: slight rotation / camera settle.
   - End on a frame that can hold as the pinned section releases into Collections.

## Scene + Art Direction
- Environment: minimal studio / craft bench suggestion (can be abstract).
- Background: neutral warm gray with subtle gradient; avoid busy workshop clutter.
- Styling: premium, editorial, RH/Apple product film vibe.
- Tools: keep minimal (e.g., chisel, plane, clamp) — tasteful, not "garage".

## Camera
- 35–50mm equivalent feel (avoid wide distortion).
- Smooth camera moves only (no shakes).

## Lighting
- Photoreal soft key + gentle fill.
- Warm tone for beat 1, slightly more neutral for beat 3.
- Maintain consistent exposure; no dramatic flicker.

## Output Deliverables
### A) Image sequence (required)
- Format: **WebP** (preferred). AVIF optional if convenient.
- Frames: **240 frames** (recommended). Range: 180–300 acceptable.
- Resolution:
  - Desktop: **1600px width** (maintain aspect; recommended 4:3 or 16:10 look)
  - Mobile: **900px width**
- Naming:
  - Desktop: `chairA_desktop_0001.webp` … `chairA_desktop_0240.webp`
  - Mobile: `chairA_mobile_0001.webp` … `chairA_mobile_0240.webp`
- Background must be consistent across frames.

### B) Poster / still frame
- `chairA_poster_desktop.webp` and `chairA_poster_mobile.webp`
- Use the final reveal frame.

### C) Optional source files
- `.blend` file (or C4D) + textures packed.

## Notes for Web Performance
- Avoid excessive DOF bokeh that turns into compression noise.
- Keep texture detail realistic but not overly sharp.
- Prefer subtle motion blur (if it doesn’t create compression artifacts).

## Licensing
- Model and textures must allow **commercial use** for ARQIA website.

## Deadline / Iteration
- First draft: low-res preview (watermarked ok) to review motion + framing.
- Final: deliver full-res sequences + posters.
